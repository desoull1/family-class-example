# Description
This is a simple console program written in C++ that collects and displays basic information about a family. The user enters the family surname, father's and mother's names and ages, and optionally information about a child (son or daughter). The program uses basic object-oriented programming concepts such as classes and inheritance. After entering the data, it prints all the information in a clear format. This project is created for learning purposes and demonstrates simple input/output and class structure in C++.

## Example:
- Enter surname of your family: Smith
- Enter name of father: John
- Father age: 40
- Name of mother: Anna
- Mother age: 38
- Do you have son or daughter? yes
- Son or daughter: son
- Name of son: Mike
- Son age: 10
